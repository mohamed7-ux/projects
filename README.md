# K-Map Solver

افتح `index.html` في المتصفح مباشرة، مفيش تثبيت ولا مكتبات.

## الملفات
- `index.html` الصفحة والتبويبات
- `css/style.css` التصميم (الوضع الفاتح والداكن)
- `js/state.js` الحالة والثوابت
- `js/ui-state.js` إعادة الضبط ومزامنة الحقول
- `js/parser.js` محلل المعادلات
- `js/kmap-render.js` رسم الخريطة
- `js/truth-table.js` جدول الحقيقة والأعمدة الإضافية
- `js/expression.js` التبويبات وحل المعادلة
- `js/solver.js` Quine-McCluskey وخطوات الحل
- `js/circuit.js` رسم الدائرة المنطقية
- `js/word-problem.js` المسائل الكلامية
- `js/main.js` ربط الأحداث والتشغيل

ترتيب تحميل الملفات في `index.html` مهم، لأنها تشترك في نفس المتغيرات العامة.

## تبويب المسألة
بيستخدم قدرة `sample` الموجودة جوه claude.ai بس. على موقعك هتظهر رسالة بدل ما يشتغل.
لتشغيله على موقعك: غيّر الاستدعاء في `solveWord` (ملف `js/word-problem.js`) ليتصل بسيرفر صغير عندك يكلّم Anthropic API، واحتفظ بمفتاح الـ API على السيرفر وليس في الصفحة.
